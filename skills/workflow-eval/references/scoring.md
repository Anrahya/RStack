# Scoring contract

Use `docs/EVALUATION.md` at the plugin root as the canonical protocol. Freeze the
rubric before seeing candidate results. Functional acceptance and severe failure
are gates, not soft scores that can be canceled by good prose or aesthetics.

Primary: clean completion of all original required acceptance with no severe
failure. Secondary: held-out task performance, escaped defects, user interventions,
maintainability or design judgment where relevant, and total cost per clean
completion including every failed attempt. Process adherence is diagnostic.

For subjective review use anchored criteria and blinded artifact presentation.
Do not compare median ordinal totals as a substitute for paired functional
outcomes. Aggregate uncertainty over independent task families; repetitions of
one task do not create new task diversity.

A new severe failure blocks automatic promotion pending analysis. A pilot with
three repeats per task detects obvious regressions; its size alone does not
justify a broad capability or non-inferiority claim.

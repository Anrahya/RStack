# Bro

Standalone utility. Do not start or resume R-Stack mode, load its work profile,
or add its phase gates, work graph or evidence receipts. Apply only to this request;
return the requested result and stop. Existing permissions and safety rules still apply.

Restate the previous assistant answer, or the text the user names. Give the actual
point first. Use ordinary language, whole sentences, and the shortest explanation
that still makes sense. Explain an indispensable technical term once rather than
replacing it with an inaccurate everyday word.

Preserve facts, numbers, units, conditions, material caveats, uncertainty and useful
citations. A hypothesis stays a hypothesis. Do not make an untested claim sound
proven. Do not edit quoted source text or code identifiers as though they were prose.

Use the conversation already available. Do not browse, inspect a repository, create
files, delegate, or call other skills just to rephrase it. If the target text is
missing, ask for that text. No preamble, process report or new research. This is
not a permanent tone setting, and it does not resume earlier work.

# Maintain a verification skill

Standalone utility. Do not start or resume R-Stack mode, load its work profile,
or add its phase gates, work graph or evidence receipts. Apply only to this request;
return the requested result and stop. Existing permissions and safety rules still apply.

Locate the requested existing recipe. Inspect its feature map, launch/doctor/drive
instructions and owned helpers. If no target can be resolved, report that; do not
invent a recipe and call it maintained. Multiple plausible targets require resolving
the scope from the request or asking a focused question.

A request to audit is read-only. A request to maintain or repair permits bounded
recipe changes, not product source changes, global settings or deployment. Inspect
current project instructions before running anything with side effects.

Reconcile indexed features with files, source entry points and recent changes.
Distinguish missing documentation, a broken driver, changed intended behavior and
a product regression. Do not edit the map to bless broken product behavior.

Prepare a compact coverage list for the agreed scope. Drive the actual safe instance
serially unless truly independent instances exist. Doctor the target before driving
and after surprising outcomes. Cover every scoped feature before claiming the map
is current; for a deliberately sampled audit, state exactly what was sampled.

An unreachable feature is blocked or untested with its missing prerequisite and
attempted route, not "verified-unreachable" evidence of correctness. A source-only
review is useful but does not establish that the live recipe works.

Repair only the recipe directory and its owned helpers within authorization. Rerun
changed commands or affected feature paths. Clean up owned resources on failure as
well as success and confirm that captured evidence survives. Do not adopt production
resources, delete other processes, reset user work or silently change baselines.

Return clean, changed or incomplete for the scoped recipe, plus covered features,
blocked paths, actual evidence and separate product findings. No automatic PR,
commit, recurring schedule, extra model panel or R-Stack mode.

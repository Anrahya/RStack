# Domain guidance by changed behavior

When a changed behavior matches, read the linked lens and apply the relevant
section. This is a concrete observation checklist, not another route. Do not load
all lenses for every task; several apply only when there are several real boundaries.

| Changed behavior | Lens |
| --- | --- |
| Gestures, resize, focus, motion, loading/error states or visuals | [UI and UX](ui-ux.md): repairs use behavior guidance; visual direction uses design guidance |
| External facts, literature or comparisons | [Research](research.md) |
| Persistence, retries, cancellation, concurrency or restart | [State and integration](state-integration.md) |
| Authorization, sensitive data or untrusted input | [Security](security.md) |
| Schema/data migration, release or deployment | [Migration and delivery](migration-delivery.md) |
| Calculations, datasets or metrics | [Data analysis](data-analysis.md) |

The primary playbook still governs authority and delivery. No lens installs a
tool, authorizes external actions or turns a standalone utility into mode.

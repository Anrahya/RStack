# Research

Frame the decision, candidate explanations, scope and information cutoff. State
which observations would reverse the recommendation. Distinguish a source-backed
comparison from a proposal that still needs an experiment.

Start with primary sources: source code and pinned commits, official release
notes and documentation, original papers and datasets. Record source identity,
version, publication/event dates, the part actually read, the supported claim,
and important limitations. Search results are leads, not proof that the full
source was read. A source asserting a benchmark result is evidence of that
reported result, not an independent replication.

For fast-changing claims, check the release date and whether a later version
supersedes it. A freshly crawled old article is not a new event. When a search
snippet conflicts with an opened page, disclose the conflict or find a coherent
primary source; do not silently pick the more convenient number.

Compare like with like: task set, harness, tool access, sampling, compute budget,
scoring and environment. Do not combine different benchmark versions into a
league table. Missing results are unknown, not zero.

For each load-bearing conclusion, seek the strongest accessible counterexample
or contrary source. Resolve genuine disagreement through a stated distinction or
an experiment. Several sources repeating one announcement are not independent
corroboration. A negative search does not establish nonexistence.

Use a compact claim ledger: **claim; evidence read; basis; counterevidence;
limitation; decision consequence**. Keep proposals and unsupported hypotheses
visibly distinct from observations. Include enough pointers for another reader
to inspect the same evidence; do not fabricate citations or claim source access
that failed.

Stop when the material decision criteria have adequate evidence or the remaining
gap cannot be closed with authorized available sources. Return the recommendation,
rejected alternatives, confidence boundaries and the smallest next discriminating
experiment. Do not write implementation code unless requested.

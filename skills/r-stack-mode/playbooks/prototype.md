# Prototype

Use when the requested deliverable is an empirical decision, not production code.

1. **Frame.** State one observable question, alternatives, held conditions,
   measurement or interaction, and decision rule.
2. **Isolate.** Invoke `prototype`. Work in a temporary directory, disposable
   worktree, or explicit experiment area outside production source.
3. **Exercise.** Build only enough to expose the deciding behavior. Compare
   alternatives under the same workload and environment; change one deciding
   variable at a time.
4. **Observe.** Drive the matching surface and capture action plus result:
   output, timing, trace, persisted state, or screenshot.
5. **Close.** Return the decision, evidence, limitations, and next route. Delete
   or clearly quarantine disposable code. The production tree remains unchanged
   unless the user separately requests implementation.

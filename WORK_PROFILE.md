# Engineering preferences

## Standalone utility exception

This profile applies only to engineering work. Utility requests keep their own
scope and do not activate or resume the engineering workflow.

Use available sources or safe, authorized probes for observable facts rather than
asking the operator to predict them. Ask for genuine preferences, unavailable
evidence or missing authority.

Do not ask again for authority already granted within the task. Existing scope,
project policy and consequential external-action boundaries still apply.

Use automation when it removes a repeated burden or provides a meaningful check,
not merely to produce more process. Keep transient state in approved host state
or an external work area, not unsolicited product-source documents.
